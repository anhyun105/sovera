# Sovera ko live aur use kaise karna hai

## Website ko live dekhna
1. GitHub repository kholo: https://github.com/anhyun105/sovera
2. Upar **Actions** tab kholo.
3. **Deploy Sovera to GitHub Pages** run complete hone do.
4. Green success status ke baad website link **Settings → Pages** ya Actions deployment summary mein milega.

## Agar deployment fail ho
- Actions tab mein red workflow run kholo aur error dekho.
- Settings → Pages mein source ko **GitHub Actions** rakho (agar option dikh raha ho).
- `index.html` aur `.github/workflows/deploy.yml` ko `main` branch mein rehne do.

## Is version mein kya chalta hai
- Black/gold Sovera landing page aur SV monogram.
- Interactive 3D garment scene, garment type, material aur colour controls.
- Illustrative 1D tech pack, 2D sketch aur auto-rotating 4D-style preview.
- Browser-local demo profile, save/publish preview, sample Explore gallery.
- Local photo overlay preview.
