# Sovera — Value your Soul

A black-and-gold fashion design studio prototype inspired by the Sovera SV monogram.

## Features
- Guest browsing and sign-in/sign-up interface
- Interactive 3D garment preview plus 1D tech-pack, 2D sketch and motion views
- Fabric, colour, silhouette, neckline, sleeves, embroidery and measurement controls
- Personal dashboard, private/public design flow and community gallery
- Supabase integration starter and Row Level Security schema
- GitHub Actions workflow for GitHub Pages

## Status
This is a deployable frontend prototype, not production-grade garment CAD or AI virtual try-on. Screenshot capture cannot be fully prevented by a website. Configure and test Supabase before inviting real users.

## Deploy
Push the project files to `main`, then open **Settings → Pages** and select **GitHub Actions**. A workflow is included under `.github/workflows/deploy.yml`.
